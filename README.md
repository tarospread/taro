# Тихая колода — статический сайт таро

Карта дня, расклады и значения 78 карт. Статика: HTML + CSS + JS, без сборки.

- `index.html` — карта дня
- `rasklad*.html`, `keltskiy-krest.html` — расклады
- `karty/`, `koloda.html`, `tablica-znacheniy.html` — значения карт
- `assets/` — стили, скрипты, карты, обои
